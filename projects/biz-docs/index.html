Dashboard Settings Clients New Document Quotation_Template Invoice_Template Receipt_Template Quotations (log) Invoices (log) Receipts (log)

วิธีติดตั้ง (5 นาที)

  1. อัปโหลดไฟล์ .xlsx ขึ้น Google Driveดับเบิลคลิก → เปิดด้วย Google Sheets ระบบแปลงไฟล์ให้อัตโนมัติ
  2. ใส่ Apps Scriptเมนู Extensions → Apps Script → ลบโค้ดเดิม วางไฟล์ Code.gs ที่แจกมาแทน แล้ว Save
  3. รีเฟรชหน้า Sheetsจะมีเมนูใหม่ชื่อ "เอกสารธุรกิจ" ขึ้นข้าง Help
  4. ตั้งค่าเริ่มต้นครั้งแรกเมนู เอกสารธุรกิจ → ตั้งค่าเริ่มต้น (รันครั้งแรก) → กด Allow ตอนขอสิทธิ์
  5. กรอกข้อมูลกิจการ + ลูกค้าชีท Settings และ Clients แล้วเริ่มออกเอกสารได้ที่ชีท New Document
⚠️ ห้ามลบ/แทรกแถวหรือคอลัมน์ในชีท Settings, เทมเพลต และ log sheets — สคริปต์อ้างอิงตำแหน่งเซลล์ตายตัว รายละเอียดครบทั้งหมดอยู่ในไฟล์ คู่มือติดตั้ง.md ที่แนบมาในซิป
