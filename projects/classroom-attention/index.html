วิธีคำนวณ Attention Score
👁️ EAR — Eye Aspect Ratioน้ำหนัก 40%
วัดอัตราส่วนความสูงต่อความกว้างของตา
EAR = (|p2-p6| + |p3-p5|) / (2 × |p1-p4|)

🔵 EAR > 0.25 = ตาเปิดปกติ → โฟกัส
🟠 EAR 0.18–0.25 = ตาหรี่/ง่วง
🔴 EAR < 0.18 = หลับตา/ก้มหน้า

Threshold ถูก calibrate ตอนเริ่มต้นตาม baseline ของแต่ละคน
🙂 Head Pose — ท่าทางศีรษะน้ำหนัก 35%
วัดมุม Yaw (หันซ้าย-ขวา) และ Pitch (ก้ม-เงย) จาก rotation matrix จริงของ MediaPipe (3D head transform)

🔵 |Yaw| < 10° และ |Pitch| < 12° = มองตรง → โฟกัส
🟠 หันปานกลาง = วอกแวกเล็กน้อย
🔴 |Yaw| > 45° หรือ |Pitch| > 42° = หันออก/ก้มหน้า

ใช้ค่าที่แย่ที่สุดระหว่าง yaw กับ pitch — หันหน้าหรือก้มหน้าอย่างใดอย่างหนึ่งก็ถือว่าไม่โฟกัส
👀 Gaze — ทิศทางสายตาน้ำหนัก 25%
วัดตำแหน่ง iris relative ต่อ eye corner จาก landmark 468 จุด

🔵 Iris อยู่กลางตา = มองไปข้างหน้า → โฟกัส
🟠 Iris เบี่ยงปานกลาง = มองเฉียง
🔴 Iris เบี่ยงมาก = มองออกไปนอกหน้าจอ
📊 คะแนนรวม
Score = EAR×0.4 + HeadPose×0.35 + Gaze×0.25

🔵 80–100% = โฟกัสดีมาก
🟡 55–79% = ความสนใจปานกลาง
🟠 35–54% = เริ่มวอกแวก
🔴 0–34% = ไม่สนใจ / ง่วงนอน
